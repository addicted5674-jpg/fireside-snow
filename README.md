# Fireside snow

A cozy animated backdrop for the Claude desktop and mobile apps: a warm living room at night with a fire flickering in the hearth, a Christmas tree twinkling in the corner, a lamp glowing, and snow falling past the window. The app's colors are themed to match, in warm browns and amber. As your context window fills, snow piles higher on the window and falls a little thicker, so you can see at a glance how full the session is.

## Install

In a Claude Code session, type:

```
/plugin install fireside-snow --marketplace addicted5674-jpg/fireside-snow
```

Answer `y` to add the marketplace, then pick a scope. The backdrop shows in the Claude desktop and mobile apps.
